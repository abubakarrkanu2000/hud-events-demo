HuD Events — Global Front-End Demo

Open index.html in any modern browser.

This version includes:
- Official HuD logo supplied by the client
- Global country selector for the event directory
- Sierra Leone sample data using the supplied A++ Seminar and Sex Sense Seminar posters
- Upcoming / past event filtering
- Responsive, tech-forward presentation
- Front-end registration flow
- Simulated Sierra Leone payment options and confirmation ticket

Important: This is a presentation prototype only. It has no backend, database, authentication, live Monime connection, or real payment processing.

To extend the demo, add event cards with a data-country attribute matching the country selector, for example:
data-country="Ghana"
